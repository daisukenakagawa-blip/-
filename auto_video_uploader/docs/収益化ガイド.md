# 収益化ガイド — このシステムでお金を稼ぐ道筋

このリポジトリの自動投稿システム(1日1本、完全自動でショート動画を4媒体に配信)を
「収益」につなげるための実践ガイドです。収益源は大きく4つあり、**達成条件が軽い順**に
並べています。上から順に整えるのがおすすめです。

> ⚠️ 収益額はコンテンツの質と再生数次第です。本ガイドは仕組みと手順の整理であり、
> 収益を保証するものではありません。

---

## 1. 説明欄リンク収益(今日から可能・条件なし)

チャンネル登録者数などの条件が一切ないため、**最初に整えるべき収益源**です。
`links.txt` に書いたリンクが全投稿の説明欄に自動挿入されます(README 7-1 参照)。

| 導線 | 始め方 | 相性 |
|---|---|---|
| ASP アフィリエイト | [A8.net](https://www.a8.net/)・[もしもアフィリエイト](https://af.moshimo.com/) に無料登録 → 案件提携 → リンク発行 | ポイ活アプリ・漫画アプリ・懸賞系はパチスロ視聴者と相性◎ |
| LINE 公式アカウント | 無料で開設 → 「狙い台情報配信」などで友だち登録を集める | 将来の有料 note・オンラインサロン等への母集団になる |
| 自分の商品 | note 有料記事(店舗攻略・立ち回りまとめ等) | 動画で信頼を貯めてから |

**ポイント**: リンクは 2〜3 個まで。多すぎると全部踏まれなくなります。
PR 表記(ステマ規制対応)はシステムが自動で付けます。

## 2. TikTok / Instagram のフォロワー獲得(拡散が速い)

同じ動画をクロス投稿するだけで媒体ごとのアルゴリズムに乗るチャンスが増えます。
特に TikTok は新規アカウントでもバズりやすく、**YouTube への流入源**としても機能します。

- `CROSS_POST_PLATFORMS=tiktok,instagram,x` を設定するだけ(README 7-2)
- プロフィール欄に YouTube チャンネルと LINE のリンクを貼っておく
- TikTok は日本では条件を満たすと報酬プログラム(長尺動画等)の対象になる

## 3. YouTube パートナープログラム(本命・ストック収益)

| 条件(いずれか) | 内容 |
|---|---|
| 登録者 500人 + 直近90日で動画3本 + Shorts 300万回再生(90日) | ファン獲得機能(メンバーシップ・Super Thanks 等)が解放 |
| 登録者 1,000人 + Shorts 1,000万回再生(90日) or 総再生 4,000時間(12ヶ月) | **広告収益の分配**が解放 |

毎日1本の自動投稿を止めないことが最重要です(アルゴリズムは継続性を評価します)。
本数を増やしたい場合は `python main.py --all` で pending を全件処理できます。

## 4. 案件・スポンサー(フォロワーが増えたら)

登録者数千人規模になると、ホール取材系メディアやアプリ案件から直接依頼が来ることが
あります。プロフィールに連絡先(メール or LINE)を書いておくだけで受け皿になります。

## 運用チェックリスト

- [ ] `links.txt` を作成した(ASP 登録 → リンク発行 → 貼り付け)
- [ ] LINE 公式アカウントを開設し、リンクを `links.txt` とプロフィールに追加した
- [ ] `CROSS_POST_PLATFORMS` を設定し、TikTok / Instagram / X の認証を通した
- [ ] スプレッドシートに 1〜2 週間分のネタを常にストックしている
- [ ] 週1回 `uploaded_log.csv` と各媒体のアナリティクスを見て、伸びたテーマ系統を
      翌週のネタに反映している(伸びたテーマの「型」を再利用するのが最短)

## 法令・規約の注意

- アフィリエイトリンクには PR 表記が必須(景品表示法・2023年10月〜)。本システムは自動付与します。
- パチンコ・スロット関連は「勝てる」「儲かる」と断定する表現を避けること(動画の免責文言は自動挿入されます)。
- オンラインカジノ関連の案件は日本では**違法性が高いため扱わない**でください。
- 各媒体の自動投稿はいずれも公式 API を使用しています(規約違反のスクレイピング投稿ではありません)。
