## STEP 1: Googleフォームを3つ作る(15分)

https://forms.google.com を開き「+」で新規作成。以下の3つを作る。

### フォーム① Agent Tools Depot(日本語)
- タイトル: `Agent Tools Depot 事前登録`
- 質問1: `メールアドレス`(記述式・必須)
- 質問2: `どんなAIエージェント/アプリを作っていますか?`(記述式・任意)

### フォーム② JDM Auction Intel(英語)
- タイトル: `JDM Auction Intel — Waitlist`
- 質問1: `Email`(記述式・必須)
- 質問2: `What chassis are you hunting?`(記述式・任意)

### フォーム③ キャンセル拾い(日本語)
- タイトル: `キャンセル拾い 事前登録`
- 質問1: `メールアドレス`(記述式・必須)
- 質問2: `どの施設・予約の空きを監視してほしいですか?`(記述式・**必須**)

各フォームで右上の**「送信」→ リンクのアイコン → URLをコピー**して控える。
→ これが「フォームURL」(3つ)

## STEP 2: 回答をスプレッドシートに出して公開する(10分)

3フォームそれぞれで:

1. フォームの**「回答」タブ → 緑のスプレッドシートアイコン**をクリック(シートが作られる)
2. 開いたスプレッドシートで **ファイル → 共有 → ウェブに公開**
3. 公開対象をそのシート、形式を **「カンマ区切り形式(.csv)」** にして公開
4. 表示されたURLをコピーして控える

→ これが「回答CSVのURL」(3つ)
(auto_video_uploader の topics 連携でやったのと同じ操作)

## STEP 3: URLを6つ、チャットに貼る(2分)

チャットに貼るだけ。**台帳への反映と観測開始処理はこちらでやる。**

## STEP 4: リポジトリが公開か非公開か教える(1分)

GitHubでこのリポジトリを開き、リポジトリ名の横のラベルを見る:
- **Public** と書いてある → そのまま進める(追加作業なし)
- **Private** と書いてある → チャットで「Privateだった」と一言。
  → LP公開専用の別リポジトリ(中身はLPだけ)をこちらで用意する

## STEP 5: GitHub Pages を有効にする(2分)

LPを置くリポジトリ(STEP 4で決まった方)で:

1. リポジトリの **Settings** タブ
2. 左メニューの **Pages**
3. Source を **「GitHub Actions」** に変更

※ Settings はオーナーしか触れないため、ここだけは代行不可。
